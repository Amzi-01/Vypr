The Vypr agent Always
Starts when you sign in, and locks a little memory for each window it shows — that is how pictures leave this VM, with no driver.
Vypr needs a signed-in desktop to show anything. Without this, someone has to sign in on the VM's own screen after every start.

Written once, into Windows' own automatic sign-in setting. It goes nowhere else and Vypr does not keep it.
